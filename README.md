# Lessig-ish Style

A SOMA app: a builder and presenter for **Lessig-style** presentations — one word/idea per
slide, revealed in time with the narration. Wonderful to watch, historically brutal to build;
this makes it an afternoon's work.

- **Landing:** `index.html` (itself a Lessig-ish scroll deck)
- **Presenter / demo:** `present.html` — word-on-voice, ElevenLabs narration, live **speed** control
- **About:** `about.html` — the Lessig Method + Lawrence Lessig, with an open invitation to connect

Built with SomaScript + SomaCut. Unaffiliated homage to Lawrence Lessig's presentation method.
Naming canon: `~/Projects/SOMA/specs/somascript-v0.md`.
